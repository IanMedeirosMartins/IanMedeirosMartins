## 👨‍💻 Sobre mim

Sou estudante de **Sistemas de Informação** e Técnico em **Análise e Desenvolvimento de Sistemas (ADS)**.

Tenho interesse em desenvolvimento de software e tecnologia, buscando evoluir constantemente através de projetos, estudos e experiências práticas.

Atualmente venho desenvolvendo conhecimentos em diferentes áreas da programação, incluindo desenvolvimento web, aplicações, APIs, bancos de dados e programação em Python.

Meu objetivo é construir uma carreira sólida na área de tecnologia, sem me limitar a uma única área do desenvolvimento.

- 💻 Desenvolvedor em formação
